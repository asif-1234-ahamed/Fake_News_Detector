📰 Fake News Detector

A simple and interactive web-based Fake News Detector that analyzes news text and classifies it as Real or Fake using basic keyword detection logic.

🚀 Demo

Paste any news headline or article and click "Check News" to see the result instantly.

📌 Features
📝 User-friendly text input
⚡ Instant result display
🎨 Clean and responsive UI
🧠 Basic keyword-based detection logic
🔴 Visual indication for fake news
🟢 Visual indication for real news
🛠️ Tech Stack
HTML – Structure
CSS – Styling & layout
JavaScript – Logic & interactivity
📂 Project Structure
Fake-News-Detector/
│
├── index.html      # Main webpage
├── style.css       # Styling file

└── README.md       # Project documentation

⚙️ How It Works
The user enters news text
JavaScript checks for specific keywords like:
"shocking"
"breaking!!!"
"100% cure"
If keywords are found → marked as Fake
Otherwise → marked as Real

⚠️ Note: This is a demo project and does not use a real Machine Learning model.
